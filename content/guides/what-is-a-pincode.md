title: "What is a PIN Code in India?"
description: "A comprehensive guide to understanding Postal Index Numbers (PIN codes) used by India Post for mail and package delivery."
---

A **Postal Index Number (PIN)**, commonly referred to as a **PIN code**, is a 6-digit numeric code used by **India Post** (the government-operated postal system in India) to uniquely identify geographical regions, sorting hubs, and delivery post offices.

### History of the PIN Code System

The PIN code system was officially introduced in India on **August 15, 1972**, by **Shriram Bhikaji Velankar**, who served as the Additional Secretary in the Union Ministry of Communications.

Before the introduction of PIN codes, manual sorting of letters and parcels was inefficient and prone to errors. India has hundreds of languages, identical place names across different states (for example, Rampur exists in several states), and varying regional scripts. The 6-digit numeric code provided a universal, machine-readable standard to route mail accurately regardless of language or script.

### Key Benefits of the PIN Code System

1. **Elimination of Linguistic Barriers**: Mail sorters can route parcels based solely on numerals without needing to translate regional dialects.
2. **Speed & Automation**: Automated and semi-automated sorting hubs use PIN codes to group mail rapidly into designated state and district bags.
3. **E-Commerce & Logistics Support**: Modern courier companies, delivery apps, and financial institutions depend on PIN codes to determine serviceability and routing.

### Summary of PIN Code Facts

- **Total Digits**: 6 digits.
- **Postal Zones**: 9 zones (8 regional civilian zones + 1 Army Postal Service zone).
- **Number of PIN Codes**: Over 19,500 active PIN codes in India.
- **Number of Post Offices**: Over 165,000 post offices nationwide.
